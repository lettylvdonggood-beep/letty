01 // Inception · 账号分析

NODE: 01.ANA
01 // 问题发现 🧠 人工

挖掘业务问题

账号调性不只是文字风格——还包括品牌想成为什么、用户为什么信任你、哪些表达不能碰。先由人发现问题，再让 AI 验证。
问题一 // 人工发现 🧠 人工

岗位帖为什么跑不动？

目前账号主推流仍然是【求职工具/模版】及【求职方法/渠道型】帖子，标签是 #领英 #简历模板 #职场干货。

但当发【岗位推荐】帖给雇主做品牌宣传时，无人买单。

人的直觉判断：平台对账号的强识别还是「求职工具 / LinkedIn / 简历面试」，而不是「岗位机会库 / 公司推荐 / 小众外企招聘」。
问题一 // AI 分析 🤖 Agent

分析这几类帖子的共性

输入：【求职工具/模版】及【求职方法/渠道型】历史帖子数据
分析维度：标签分布、受众画像、互动模式
AI 输出结论：发岗位帖时，很可能先被推给「想学方法、想看情绪共鸣」的人，而不是「正在找具体岗位的人」。这批人看到岗位帖，点击和互动弱，导致岗位帖过不了初始流量池。
问题二 // 人工发现 🧠 人工

为什么有些岗位帖🔥
但其余跑不过？

在岗位/公司发布的帖子中，也有几个火爆的岗位帖在跑。

人的直觉判断：火的帖子和不火的帖子之间一定存在某种结构性差异，不只是运气。
问题二 // AI 分析 🤖 Agent

分析🔥帖子的共性

输入：火爆岗位帖 vs 普通岗位帖
对比维度：标题结构、封面风格、切入角度
AI 输出结论：火爆帖子都在回答「我这种人能不能投？」——
· BuildHealth：英语不好、学历普通的人也能看
· RealityHoliday：有生活想象 + 岗位明确 + remote 真实可投
· 欧洲咨询公司：经验少的人也能进咨询公司

而跑不动的帖子都在说「这家公司有什么福利？这家公司是不是不错？」——从「帮用户打消顾虑」变成了「展示公司福利/公司很牛」。
03 // 人工审核 🧠 人工

审核分析逻辑，确认结论

核心洞察确认：用户原本以为自己不够格，但你告诉她「这类人也有机会」——这才是岗位帖的正确切入角度。

行动决策：
· 不抛弃工具类和情绪类用户，而是把她们「养熟」成岗位用户
· 不要强行改成纯岗位号，做成：求职方法带岗位、情绪痛点带岗位、公司推荐带路径
· 内容比例调整：70% 岗位推荐 / 10% 工具方法 / 10% 情绪故事 / 10% 合集资源
最终输出：账号调性记忆文件，Agent 后续环节可调用 → 流转至环节二

02 // Visual · 封面风格制作

NODE: 02.CVR
01 // 前置思考 🧠 人工

定义思考问题

人在前期想好思考问题和逻辑，AI 无法替代这一步
问题框架：
① 这家公司调性是什么样子？
② 这家公司关键词是什么？
③ 这家公司在讲什么故事？
④ 这家公司加入后是什么样的画面？
02 // 思考逻辑 🧠 人工

定义视觉逻辑

核心原则：画面能够代表内容在讲什么——用画面在讲故事，而不只是在传递信息；画面和内容完全共振。

封面公式：一张有质感/有故事的图 + 几个大字点明主题 + 1-2个差异化标签击中痛点 + 清晰的品牌标识

视觉规则：
· 深底色 + 高饱和亮字 + 真实场景图
· 小红书大部分帖子偏暖偏白偏粉，深色/暗调背景天然是「异类」，会打断滚动节奏
· 自然场景的绿色和蓝色也很能留住目光
03 // AI 输出 🤖 Agent

生成封面风格关键词

Agent 根据公司信息 + 视觉逻辑，输出可执行的搜索关键词
输入：公司名称
输出维度：
① 这家公司的调性关键词
② 这家公司在讲什么故事
③ 能够和这家公司共振的画面什么样子
④ 可以在 Pinterest 搜索图片的相关关键词
执行：拿到关键词后，在 Pinterest 寻找共振画面 → 流转至环节三

03 // Copy · 封面文案制作

NODE: 03.TAG

用户心理洞察

人在前期想好思考问题和逻辑

利益钩子（打消顾虑）：
门槛不高普通人也能投女性友好初级友好英语友好适合转行非技术岗

生成封面差异化标签

输入：公司信息 + 钩子体系
输出：
· 2 个最能引发人好奇心的差异化标签（公司钩子）
· 2 个最能打消不敢投递顾虑的差异化标签（利益钩子）
产出：封面差异化标签方案 → 流转至环节四

04 // Title · 正文标题

NODE: 04.TTL
01 // 前置判断 🧠 人工

判断公司知名度

人在前期想好思考问题和逻辑
① 需要判断这家公司是否有知名度
② 有知名度 → 直接按模版来
③ 没知名度 → 衡量哪种写法更击中人群

核心规则：标题负责搜索+点击，达到搜索编辑效应最大化。必须按照模版，最好有人群钩子/公司钩子/利益钩子 + 行动暗示！
02 // 模板体系 🧠 人工

定义标题模板

有知名度：【公司名】+【公司钩子】(开放X个岗位/有X个HC) +【可内推/可refer/国内可申】
例：Canva + 开放6个远程岗
例：Airbnb + 开放40+远程岗
例：设计人的梦中情司Canva可画 + 有21个HC！
没知名度 A：【人群钩子】+【可以试试这家】+【公司钩子】
例：英语一般的 + 可以试试这家 + 小众外企👀
例：英语一般的 + 可以试试这家 + 百年旅游外企🙋
没知名度 B：【公司类型】+【正在捞人/招人中/正在远程岗】+【公司钩子/利益钩子】
例：欧洲咨询公司 + 正在招人 + 初级友好
例：北美AI外企 + 正在远程岗 + 非技术也有机会
例：北美科技外企 + 招人中🙋 + 40+远程岗国内可申
没知名度 C：【这家全员remote/远程的】+【公司钩子】+【公司钩子/利益钩子】
例：这家全员remote的 + 小众外企 + 文科生大胆冲！
例：这家全员远程的 + 宝藏外企 + 捞人啦2个HC
没知名度 D：【人群钩子】+【公司类型】+ 大胆投 +【利益钩子】
例：空窗期的姐妹 + 宠物外企 + 大胆投 + 女性友好
03 // AI 输出 🤖 Agent

生成正文标题

输入：公司信息 + 知名度判断 + 模板体系 + 钩子库

行动暗示词库： 可内推国内可申大胆投大胆冲招人中
产出：5 个候选标题（已排序）→ 流转至环节五
