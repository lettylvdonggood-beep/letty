挖掘业务问题

账号调性不只是文字风格——还包括品牌想成为什么、用户为什么信任你、哪些表达不能碰。先由人发现问题，再让 AI 验证。
02 // 问题发现🧠 人工

岗位帖为什么跑不动？

目前账号主推流仍然是【求职工具/模版】及【求职方法/渠道型】帖子，标签是 #领英 #简历模板 #职场干货。

但当发【岗位推荐】帖给雇主做品牌宣传时，无人买单。

人的直觉判断：平台对账号的强识别还是「求职工具 / LinkedIn / 简历面试」，而不是「岗位机会库 / 公司推荐 / 小众外企招聘」。

英文简历帖 · #简历模板 #英文简历 #求职
02 // AI 验证🤖 Agent

分析这几类帖子的共性

输入：【求职工具/模版】及【求职方法/渠道型】历史帖子数据
分析维度：标签分布、受众画像、互动模式
AI 输出结论：发岗位帖时，很可能先被推给「想学方法、想看情绪共鸣」的人，而不是「正在找具体岗位的人」。这批人看到岗位帖，点击和互动弱，导致岗位帖过不了初始流量池。

为什么有些岗位帖🔥
但其余跑不过？

在岗位/公司发布的帖子中，也有几个火爆的岗位帖在跑。

人的直觉判断：火的帖子和不火的帖子之间一定存在某种结构性差异，不只是运气。

03 // AI 验证🤖 Agent

分析🔥帖子的共性

输入：火爆岗位帖 vs 普通岗位帖
对比维度：标题结构、封面风格、切入角度
CASE STUDY: 2 VIRAL POSTS
① BuildHealth — 打的是：英语不好、学历普通的人也能看
涨粉 74 · 互动 971 · 超过99%同类
② RealityHoliday — 打的是：有生活想象 + 岗位明确 + remote 真实可投
涨粉 23 · 互动 426 · 超过96%同类
AI 输出结论：火爆帖子都在回答「我这种人能不能投？」

而跑不动的帖子都在说「这家公司有什么福利？」——从「帮用户打消顾虑」变成了「展示公司福利/公司很牛」。

核心洞察：用户原本以为自己不够格，但你告诉她「这类人也有机会」——这才是岗位帖的正确切入角度。

02 // Cover System · 封面制作

NODE: 02.CVR
01 // 目的定义🧠 人工

定义封面的作用

目的：在让 AI Agent 产出封面之前，需要先想明白封面到底承担什么任务。封面不是装饰，而是信息流里的「拦截器」——它只有两个使命：

A. 让人在刷信息流时抓住注意力、停下来 — 视觉层面的拦截，靠画面、色彩、构图在一秒内让人下意识「打断滑动惯性」。

B. 留适当的钩子引起让人点击的欲望 — 文案层面的牵引，靠标签、文字、痛点回应让人觉得「这条跟我有关，我要点进去看」。

逻辑：这两个使命对应两条并行路径：Path A 解决「视觉风格如何让人停下来」，Path B 解决「封面文案如何让人点进去」。

PATH B · 封面文案
A-02 // 规律研究🧠 人工 🤖 Agent

什么样的封面可以吸引人的注意力让人停下来？

人先发现值得研究的问题并筛选样本，AI 再从样本中拆解可复用的视觉规律
人的发现：同样是招聘封面，有些会让人下意识停下来、想点进去看；有些即使信息完整，也会被快速划走。

人的动作：我把所有能吸引我继续研究的封面都截图下来，整理成封面样本 P1-P6。

AI 的动作：把 P1-P6 抛给 AI，让它从颜色、场景、构图、文字层级、品牌气质和情绪氛围中分析共性，最后得到 P8 的结论。

分工逻辑：人负责发现问题、判断哪些封面真的有点击欲；AI 负责把直觉样本结构化，提炼成后续可复用的封面特征。
封面样本 P1-P6：让我产生点击欲的招聘封面
P1 · 强品牌识别 + 高利益点
P2 · 明亮色块 + 加入邀请
P3 · 低机位真实场景 + 故事感
P4 · 自然场景 + 高饱和亮字
P5 · 质感物件 + 岗位清晰
P6 · 深底色 + 信息密度
P8：AI 输出的封面共性结论
  • 深底色 + 高饱和亮字 + 真实场景图最容易让用户在信息流里停下来。
  • 高饱和暖色最抢眼，红、橙、黄在视觉优先级上天然靠前。
  • 小红书招聘封面大多偏暖白、偏粉、偏浅色，深色或暗调背景天然更像"异类"，能打断滚动节奏。
  • 自然场景里的绿色和蓝色也很容易留住目光，因为它们有真实感、空间感和向往感。
A-03 // 逻辑定义🧠 人工

定义视觉逻辑

核心原则：画面能够代表内容在讲什么——用画面讲故事，而不只是传递信息；画面和内容完全共振。

核心逻辑：封面先让人停下来，文案再让人点进去。视觉负责"停下"——用真实场景、高识别色彩、强情绪氛围和目标用户会共鸣的审美，在一秒内打断信息流。

封面公式：一张有质感/有故事的图 + 几个大字点明主题 + 1-2个差异化标签击中痛点 + 清晰的品牌标识

视觉规则：
· 深底色 + 高饱和亮字 + 真实场景图
· 小红书大部分帖子偏暖偏白偏粉，深色/暗调背景天然是「异类」，会打断滚动节奏
· 自然场景的绿色和蓝色也很能留住目光

03 // Title · 标题输出

NODE: 03.TTL
01 // 目的定义🧠 人工

定义标题目的与思考逻辑

目的：标题在小红书承担双重任务：搜索 + 点击。要让搜索编辑效应最大化，标题里必须包含能被搜到、又能引发点击的关键词——公司名、岗位名、行业词、内推/refer/国内可申/招人。

逻辑：但这些关键词的组合方式取决于一个前提：用户认不认识这家公司。

如果公司有知名度，「公司名」本身就是最大的搜索入口和点击钩子，直接按模版走就行；如果公司没知名度，「公司名」反而是噪音，需要用人群钩子、利益钩子或公司类型来替代它，让标题击中正确的人群。

所以让 AI 在第一步就判断公司知名度，不是随意设计的——而是因为这个判断直接决定了后续标题公式的走向：用哪个模版、填什么关键词、怎么排列组合，都从这一步分叉。
02 // 问题设计🧠 人工

设计 AI 推理框架

人为 AI 设计判断路径——AI 不知道「知名度」对标题有什么影响，需要人告诉它判断规则和分叉逻辑
① 需要判断这家公司是否有知名度
② 有知名度 → 直接按模版来
③ 没知名度 → 衡量哪种写法更击中人群

02 // 问题诊断🧠 人工

诊断原话术问题

优化前 · 原始私信话术
诊断出的核心问题：

a) 跳过问题直接引导加群，触发用户防御心理。用户来私信通常带着具体问题（想了解远程岗位），但话术没有回应用户的问题，上来就让人加群——这种「不回答、先拉群」的模式和微商、诈骗账号的行为高度相似，会让用户下意识产生反感和不信任。

b) 操作路径模糊，用户觉得麻烦而放弃。只说「进去看置顶找到我」，但没有说清楚每一步具体做什么。用户看到一团模糊的指令，觉得流程复杂、不确定结果，很容易直接放弃。

c) 行业信任危机加剧用户警觉。小红书上存在大量类似操作模式的账号——也是引导加群、引导加微信，但最终目的是收费或骗取个人信息。用户在过去可能已经踩过坑，所以对任何「加群」「加微信」的引导都会本能地保持警惕。
02 // 话术优化🧠 人工 🤖 Agent

重新设计引导话术

针对诊断出的三个问题，逐一设计对应的信任修复策略
优化后 · 版本 A
优化后 · 版本 B
优化策略与对应逻辑：

a) 先解释「为什么不能直接发链接」→ 主动打消用户顾虑。开头就说明「具体的 refer 链接这里发不了会被吞或者被封」——把「不直接给链接」这个反常行为的原因提前交代，让用户理解这是平台规则限制而不是故意隐藏，从根源上消除「为什么不直接给我」的疑虑。

b) 用数字编号拆解每一步操作 → 缓解用户焦躁。把引导动作拆成 ①②③ 三步清晰指令，每一步都是一个简单动作。用户不需要猜「接下来做什么」，看到编号就知道流程短、步骤明确——降低「太麻烦了不想弄」的心理门槛。

c) 加微信后直接展示具体操作关键词 → 即刻消除用户疑虑。话术里直接写明「发送【XX 内部招聘】」「发送【申请 XX】」——用户还没加微信就已经知道加了之后要做什么、会得到什么。这种「提前透明」让用户感知到这确实是一个正规的投递渠道，而不是加了微信之后才发现是另一回事。

d) 主动声明免费且提醒防骗 → 直接击碎最大顾虑。话术末尾加上「我们只负责内推不收取任何费用，如其余账号投递岗位收取费用可能为虚假渠道请多注意辨别」——把用户最核心的担忧（会不会收钱、会不会被骗）提前说破，而不是等用户自己去猜。这种「先于用户开口打消顾虑」的写法，本身就是一种信任建设。

结论：私域转化率不是靠「更多曝光」解决的，而是靠精准击碎用户的每一个信任障碍——解释规则、拆解步骤、提前透明、主动声明。话术设计的本质是「信任工程」。

三组对比回答了一个核心问题：AI Agent 到底有没有用？

核心结论：数据证明了这套方法论的有效性——人负责定义问题、设计逻辑、判断优先级；AI 负责分析数据、提炼规律、批量执行。不是「人 or AI」，而是「人 × AI」。
